# Security reports

Do not post PINs, local addresses, personal screenshots, exploitable details, or device logs in public issues.

Use this repository's GitHub **Security → Report a vulnerability** page for a private report. If that option is unavailable, first open a public issue asking for a private contact without disclosing the vulnerability.

This app is an optional local-network family tool. It is not a device owner, kiosk, or replacement for operating-system parental controls. Known limitations are documented in docs/privacy.md.
